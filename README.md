# FieldTape for Kaggriculture

Two deliberately isolated workspaces:

- `agent/` — private, deterministic Kaggriculture competition research and submission code.
- `fieldtape/` — public-safe playable game, spectator, and quant-learning laboratory.
- `supabase/` — optional free-tier persistence, daily challenges, and verified leaderboard backend.

FieldTape is an unofficial educational project inspired by Kaggle's Kaggriculture simulation. Kaggle and Kaggriculture are trademarks of their respective owners. The public product does not contain the private competition policy, opponent data, or competition replay payloads.

See each workspace README for setup and verification.
